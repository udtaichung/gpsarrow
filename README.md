# 軌跡箭頭 (gpsarrow)

給單車／機車騎乘用的極簡 GPX 軌跡導航網頁。不畫地圖、不連線、不耗電——只回答一件事：**現在該往哪裡騎**。

## 畫面

上下兩格：

- **上格：箭頭**。螢幕上方＝你的前進方向，箭頭指向前方軌跡上的前瞻點。偏離軌跡時箭頭直接指回最近的軌跡點。
- **下格：軌跡形狀**。前方 100–500 公尺（可調）的實際軌跡線形，行進方向朝上。含距離刻度、偏離門檻圈、起點／終點記號。

偏離超過設定距離時，整片畫面轉紅、發出警告音並震動。持續偏離時警告間隔會逐次拉長（8s → 16s → 32s → 60s），刻意繞路不會被一直打擾。

## 方向

GPX 格式本身沒有「方向」欄位——**點的排列順序就是方向**，第一個 `<trkpt>` 是起點、最後一個是終點。

起始畫面會顯示「起點 → 終點：朝 東北（42°）」讓你確認方向對不對，旁邊的按鈕可隨時反轉，且反轉是**可逆的開關**（保留原始點序，來回切換不失真），選擇會被記住。環狀路線會另外標示，因為此時方位角沒有意義。

## 使用

1. 用瀏覽器開啟 [GitHub Pages 網址](https://udtaichung.github.io/gpsarrow/)
2. 選擇 GPX 檔，確認方向，按「開始」
3. 授權定位與動作感測（iOS 會另外詢問羅盤權限）

也可以把 GPX 放在同一個資料夾，用 `?gpx=檔名.gpx` 開啟自動載入。

**注意**：請勿用 `file://` 直接開啟本機檔案——瀏覽器會擋掉 `?gpx=` 的自動載入，離線快取（Service Worker）也不會註冊。請用 GitHub Pages，或在本機跑一個 http 伺服器：

```
python -m http.server 8000
```

## 離線

安裝成 PWA（Chrome「加入主畫面」／Safari「加入主畫面」）後可完全離線運作。App 本體與讀取過的 GPX 都會被快取，山區沒訊號時仍然開得起來。

## 設定

| 項目 | 範圍 | 說明 |
|---|---|---|
| 偏離警告距離 | 10–150 m | 超過即轉紅警告 |
| 箭頭前瞻距離 | 20–200 m | 箭頭看多遠的軌跡；實際會隨車速在 0.6×–2.2× 之間浮動 |
| 下格顯示範圍 | 100–500 m | 軌跡形狀的可視距離 |
| 警告音 | 開／關 | 震動不受此開關影響 |
| 軌跡方向 | 正向／反向 | 可逆 |
| 重新定位到軌跡 | — | 折返路段或多圈賽道吸附錯位時的逃生口 |

所有設定會存在 localStorage，下次開啟沿用。

## 方向來源

騎乘中 GPS 航向（`coords.heading`）遠比電子羅盤可靠——手機裝在車把上會受金屬與震動干擾。因此：

1. 優先使用 GPS 航向（需車速 > 1.2 m/s，8 秒內有效）
2. 退回電子羅盤
3. 兩者皆無：箭頭轉灰並提示「先往前騎一段」，下格改以軌跡本身的方向朝上（形狀仍然可讀）

## 技術

單一 HTML 檔，無任何相依套件。距離採 haversine，近距離幾何以切平面近似（以當前位置為原點，短距離誤差可忽略）。沿軌里程用累積表 + 二分搜尋定位；軌跡比對在鎖定後只搜尋前後一段（後 400 m／前 1500 m），避免折返路段誤吸到別的地方。
